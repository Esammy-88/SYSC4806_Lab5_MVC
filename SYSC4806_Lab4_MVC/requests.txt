SYSC 4806 Lab 5 - HTTP requests used to populate and view the address book
===========================================================================

Start the app (mvn spring-boot:run, or run AddressBookApplication in IntelliJ).
The database is in-memory and starts empty, so the first address book is id 1
and the first buddies are ids 1 and 2.

The curl commands below use quoting that works in Windows cmd.exe.
(On Linux/macOS, use single quotes around the JSON instead of escaped double
quotes. In PowerShell, call curl.exe rather than curl.)
The same requests are in requests.http for IntelliJ's HTTP client.

1. Create an address book
   curl -i -X POST http://localhost:8080/api/addressBooks -H "Content-Type: application/json" -d "{}"

2. Create two buddies
   curl -i -X POST http://localhost:8080/api/buddyInfos -H "Content-Type: application/json" -d "{\"name\":\"Alex\",\"phoneNumber\":\"613-555-0101\",\"address\":\"1125 Colonel By Dr\"}"
   curl -i -X POST http://localhost:8080/api/buddyInfos -H "Content-Type: application/json" -d "{\"name\":\"Jordan\",\"phoneNumber\":\"613-555-0102\",\"address\":\"75 Laurier Ave E\"}"

3. Add each buddy to address book 1
   curl -i -X POST http://localhost:8080/api/addressBooks/1/buddies -H "Content-Type: text/uri-list" -d "http://localhost:8080/api/buddyInfos/1"
   curl -i -X POST http://localhost:8080/api/addressBooks/1/buddies -H "Content-Type: text/uri-list" -d "http://localhost:8080/api/buddyInfos/2"

4. Check the buddies of address book 1 as JSON
   curl http://localhost:8080/api/addressBooks/1/buddies

5. View the address book through the Thymeleaf template
   Open http://localhost:8080/addressbook/1 in a browser
   (or: curl http://localhost:8080/addressbook/1)
